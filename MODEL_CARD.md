# Model card: nepotato Procedural Three.js GPU

## Identity

- **Canonical name:** nepotato Procedural Three.js GPU
- **Object class:** fictional triple-fan desktop graphics card
- **Representation:** editable procedural Three.js geometry
- **Source:** TypeScript; no imported mesh or texture assets
- **License:** MIT
- **Canonical URL:** https://github.com/arar228/nepotato-threejs-gpu

## Geometry and materials

The model contains a front shroud, three fan assemblies, backplate, PCB,
heatsink, heat pipes, PCIe connector, I/O bracket, power sockets, fasteners and
four emissive LED channels. Materials use Three.js physical and standard PBR
shaders.

## Interaction

The fan rotors are exposed through `getNepotatoGpuRotors()`. The demo supports
pointer rotation and zoom. Reduced-motion preferences stop rotor animation.

## Intended use

Web visualization, product-design concepts, demos, education, creative coding,
commercial websites, AI-assisted development and machine-readable code examples.

## Limitations

This is a fictional visual design rather than an engineering CAD model. Hidden
internal structure and dimensions are artistic assumptions. It is not affiliated
with a GPU manufacturer and must not be presented as an actual commercial model.
